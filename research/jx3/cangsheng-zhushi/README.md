## 入库硬规则
1. 可用于**正式服事实**的技能ID须有当季客户端实表或与当季相符的官方/可靠实时数据库数据和对应版本号。
2. 名称→ID ≠ 本版本有效；技能ID ≠ BuffID；技能面板 ≠ 全技能；奇穴主动 ≠ 面板常驻。
3. 有GCD、无GCD、技能冷却、控制持续时间均不能凭印象填；逐项给来源或测量记录。
4. 每条数据须包含版本、日期、心法、派生/替换关系、来源URL和核验状态。
