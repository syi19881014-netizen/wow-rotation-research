# 天策PVP状态机：研究草案（非成熟实战打法）

## 输入与模块
- 输入：当前心法及奇穴、战意、技能可用状态、自己/目标Buff、控制与免控状态、目标距离/面向/视线、队友集火信号。
- 核心状态：`SURVIVE` 自保；`PRESSURE` 平压；`PREPARE_SETUP` 准备抓点；`CONTROL_CONFIRM` 控制确认；`BURST` 爆发；`CHASE` 追击；`RESET` 退出/等待。
- 退出条件优先于固定连招：解控、免控出现、目标离开范围、队友无法配合、自身濒危、目标已被保护。

## 建议先做“决策正确性”而非自动执行
```text
若自身急需保命 -> SURVIVE（依据真实控制与伤害威胁，而非单纯血量阈值）
否则若拥有抓点所需资源且可控/可达/队友可配合 -> PREPARE_SETUP
控制命中才可 -> CONTROL_CONFIRM -> BURST
控制失败或目标免控 -> RESET/PRESSURE
平时 -> PRESSURE (资源获取、减疗/持续伤害管理)
```

## 2026年9月8日官方提出的研究分支
- 破重围：有代价封轻功 + 抓点补伤害，测定实际代价与控制链。
- 戎行：出伤前置与延迟压力，研究先决状态和后续结算。
- 流血：评估覆盖、刷新、持续时间、驱散和击杀窗口。
这些是**武学调整方向**而非10月29日正式服效果说明。

## 外部接口待确认
判断自己的CD、战意、Buff，敌方的增益/减益、真实控制状态、距离与视线，按官方允许的接口能力逐项核实。辅助提示与自动施法是不同的行为；对非法宏处罚和合规性需单独审查。
