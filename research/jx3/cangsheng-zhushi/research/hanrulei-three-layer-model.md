# 撼如雷：按技能与Buff分层，不能混同名称

**最后分析日期：2026-10-30。数据证据：JX3BOX 2026-10-13原始技能/Buff快照，及2026-10-30九重奇穴快照。尚未得到10月29日后正式服客户端实测。**

## 五种必须区分的ID语义

| 名称/对象 | ID空间 | 编号与等级 | 来源给出的效果 | PVP决策用途 |
|---|---|---|---|---|
| 撼如雷（按键主动技能） | SkillID | 主候选`404`，Level=0（原始表等级） | 施放后施加长效团队增益，自己获得短时激雷；特殊派生有444/445 | **是否准备释放**，不能据此认定激雷已触发 |
| 撼如雷（长时基础团队增益） | BuffID/Level | `362`，源表等级1～8；8级文本是外功基础攻击力、最大气血各+5% | 源表 `Count=1, Interval=28800` 帧；结合历史描述为约30分钟 | **状态维护**，不代表爆发在持续 |
| 激雷（对小队的短时加强） | BuffID/Level | `6363:1` | 外功基础攻击力与外功破防值各+20%；`6×16=96` 帧，对应约6秒 | 团队短时增伤，**不可与自身激雷等级2混为一谈** |
| 激雷（自身普通爆发） | BuffID/Level | `6363:2` | 外功会心率+30%；`24×4=96` 帧，对应约6秒 | 自己的**爆发窗口** |
| 激雷（自身加强爆发） | BuffID/Level | `6363:3` | 外功基础攻击力+20%、外功破防+20%、会心率+30%；同样96帧约6秒 | 根据等级判断自身爆发内容 |
| 激雷（自身特殊延长版） | BuffID/Level | `6363:4` | 无视目标外功防御70%、外功会心率+30%；`48×4=192`帧对应约12秒 | 特殊爆发版本；与当季「夜征」描述的持续时间翻倍吻合 |
| 激雷（关联AP加成） | BuffID/Level | `10697:1` | 原始表基础外功攻击+10%；128帧约8秒 | **特殊附加候选**，触发条件未核实；不能无条件认为随撼如雷出现 |
| 激雷（第六重奇穴选项） | 奇穴技能ID（不是BuffID） | `6806` | 当前奇穴文本：施放撼如雷后队友破防与基础攻击+20%，持续6秒 | 判断是否点出该奇穴，不得用于自身短时Buff判断 |

**注意：`6363` 的等级并非普通增益“叠层数”，而是不同效果版本。Buff等级、剩余时间、来源目标必须作为独立字段。** 不同等级是否能在同一角色身上共存，须实测，不假定。

## 对自动循环最重要的决策规则

```text
# 三类事实分别读取，禁止用一个“撼如雷Buff”布尔值判断所有状态
hanrulei_spell_ready         := 主动技能404是否可用（需当季ID确认）
hanrulei_long_buff_present   := 自身/队友是否有BuffID 362（等级、余时分别读）
jilei_self_burst_present     := 自身BuffID 6363且Level属于(2,3,4)
jilei_self_burst_level       := 实际读到的Buff Level (2/3/4)
jilei_self_burst_remaining   := 实际Buff剩余秒数
jilei_party_burst_present    := 目标/队友是否有6363 Level 1
talent_jilei_selected        := 第六重奇穴6806已点（当季版本）
talent_yezhen_selected       := 第六重奇穴5678已点（当季版本）

# 优先级：开爆发是否合适 ≠ 长Buff是否存在
if jilei_self_burst_present:
    进入短时爆发收益评估（检查抓点、目标免控、自己是否可行动）
elif hanrulei_spell_ready AND 爆发计划允许:
    安排撼如雷释放
elif NOT hanrulei_long_buff_present AND 非关键战斗阶段:
    提醒补长效增益；不能强制用掉需要留给抓点的主动爆发技能

# 不能写成：
if NOT buff(362): cast(404)     # 错：把长效Buff维护当成开爆发条件
if buff(362): BURST             # 错：30分钟增益不等于6秒短爆发
if buff(6363): BURST            # 不完整：可能是给队友的1级激雷，需要检查来源和等级
```

注：上述代码是研究状态机伪逻辑，不保证官方宏或插件能够读取Buff等级，也不表示允许第三方自动施法。

## 待实机核验
1. `404` 主动技能的正式服ID、GCD、独立CD、实际触发时间与战斗日志技能ID。
2. 新版Buff `362` 的实际等级与是否30分钟；Buff应用范围是自己、队友还是附近团队成员。
3. 新版Buff `6363` 的实际等级对应关系；小队1级是否和自身2/3/4级共存。
4. 第六重「激雷」「夜征」组合是否互斥/如何选择；在不同PVP构筑下究竟触发哪一级。
5. `10697`、`2766/2767` 是不是实际参与当前激雷机制；暂时列为候选，不参与自动循环判断。
